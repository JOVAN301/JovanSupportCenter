# Jovan Support Center System v4

## Added
- My Activity screen for logged-in users.
- My support requests with live status from the API.
- My contributions with pending/successful/failed status.
- In-app notifications from verification/rejection events.
- Live contribution-recording flow for verified server requests.
- Authentication required before recording a contribution.
- Android API methods for contributions and notifications.

## Important
Contributions are still records of payment intent/status only. No real money is transferred by this prototype. A production payment provider, verified webhooks, reconciliation, refunds, and secure server-side payment handling are required before accepting real funds.
